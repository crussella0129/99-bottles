# **99 Bottles**

A collection of attempts at https://code.golf/99-bottles-of-beer#python, some just made for nice linting rather than shortest possible syntax. Always helps to brush up on the old python skills. 

**New here?** [TUTORIAL.md](TUTORIAL.md) walks through each attempt round by round, what it taught, and three more rounds down to 241 bytes. Run `python check.py wallbeers*.py` to judge them yourself.
